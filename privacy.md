To ensure application stability and fix software bugs, sfsim automatically logs
technical error reports when an unexpected error occurs.

What we collect: Anonymized stack traces, exception codes, and basic error logs.

What we DO NOT collect: No personal data, user credentials, system metrics,
hardware specs, or personal files.

This technical data is processed solely for debugging purposes and is never
shared or used to identify you.
