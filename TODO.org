** Physics notes
*** Stable log determinant
    #+begin_src python
    def stable_log_det(z):
        r = torch.norm(z, dim=-1, keepdim=True)
        log_radial_squash = 2.0 * (math.log(2.0) - r - torch.nn.functional.softplus(-2.0 * r))
        log_surface_area = torch.where(
            r < 1e-3,
            - (r**2) / 3.0,
            torch.log(torch.tanh(r) + 1e-8) - torch.log(r + 1e-8)
        )
        return 2.0 * log_surface_area + log_radial_squash
    #+end_src

*** Reentry heating / pressure
- local pressure C_p = C_p,s sin^2(theta), where C_p,s is stagnation point pressure
- convective heating at stagnation point:
  q_c,s = k rho^N1 V^N2
- N1 = 0.5
- N2 = 3
- k = 1.83e-4 / sqrt(R_n)
- R_n = nose radius
