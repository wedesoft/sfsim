I’ve released version 0.33-1 of the [sfsim][1] space flight simulator.
This bug-fix release includes three changes aimed at improving stability:

1. Switched back from Java 27 to the stable Java 25 LTS release.
2. Fixed infinite recursion when determining which cube face an edge point belongs to.
3. Fixed an infinite loop caused by a negative opacity step size when computing cloud shadows.

![spacecraft flying through clouds](/sfsim/pics/cloudy.jpg)

If you encounter any further problems, please report them in the [sfsim playtest discussion forum][2].
See the [support page][3] for instructions on how to submit your log file.
